# Java Experiments

**Practice projects exploring file handling, timing, audio/video processing, and problem solving.**

This repository preserves learning code rather than presenting one finished application.

## Explore

- [Dictionary.java](Dictionary.java): dictionary experimentation.
- [file_creation.java](file_creation.java): file-creation practice.
- [TimedTests/](TimedTests/): experiments including equation solving, audio timing, video merging, and image-light measurements.

## Setup and scope

Use a Java Development Kit and inspect each class's imports and entry point. Some experiments rely on local media, machine-specific paths, or external libraries; there is no shared build configuration. Compile standalone classes individually after checking those requirements.

Computer-scanning experiments should be used only on your own files and devices. These are learning exercises, not production utilities.
